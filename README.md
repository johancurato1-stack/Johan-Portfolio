# Johan Garcia — Developer Portfolio

A personal developer portfolio built to showcase my projects, technical skills, and journey as a developer.

## Overview

This portfolio serves as a central place to present my development work, highlight the technologies I use, and share selected projects.

## Getting Started

To run the project locally:

**1. Clone the repository**

```bash
git clone https://github.com/johancurato1-stack/Johan-Portfolio.git
```

**2. Navigate into the project**

```bash
cd Johan-Portfolio
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
